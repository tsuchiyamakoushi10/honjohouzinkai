# 本庄法人会 HPリニューアル

公益社団法人 本庄法人会（https://www.honjohojinkai.jp/）のリニューアルサイト。
目的は **入会者を増やすこと**。「法人会とは → 活動 → メリット → 入会・問い合わせ」をストレスなくたどれる導線にしています。

- 技術：Next.js 15（App Router）/ React 19 / TypeScript 5 / 素のCSS（`app/globals.css`）
- デプロイ：GitHub → Vercel（Pro）
- 内容：**現行サイトの掲載内容をすべて移植**（文言・数字・表・PDF・画像・リンク・お知らせ全51件）。`lib/content.ts` と `lib/news.ts` に集約

---

## セットアップ

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 本番ビルド確認
```

> TypeScript は **5系に固定**しています。7系（ネイティブ版）は Next.js の設定読み込みが失敗するため上げないこと。

## GitHub → Vercel

```bash
git add -A && git commit -m "初回：本庄法人会リニューアル"
git remote add origin git@github.com:<owner>/honjo-hojinkai.git
git push -u origin main
```

Vercel で Import → Framework は Next.js 自動判定、環境変数は不要。全ページ静的生成です。

## トップページの流れ

1. **HERO**：宿場町（`public/images/hero.webp`）＋アニメーション
   - 藍色の暖簾が4枚、上に巻き上がって開くオープニング
   - 画像がゆっくり寄りから引いていく（Ken Burns）＋彩度が戻る
   - キャッチ3行が下からせり上がる → 本文 → ボタンの順に表示
   - 右に「中山道」「本庄宿」の縦看板が落ちてくる
   - `prefers-reduced-motion` の人にはアニメーション無効
2. **数字**：858社 / 全国441会 / 年間1,900名参加 / 年会費6,000円〜
3. **お知らせ**：メインビジュアルの直下に常に最新3件（`news` の先頭3件）
4. **法人会とは**
5. **入会すると、できること**（4つのメリット）
6. **会員特典 商店街**：特典を「保障・学び・交流」の3つの通りに分け、暖簾付きの店舗カードで表示（モール案）
7. **活動実績**：4事業カード＋全国表彰
8. **入会までの流れ**：STEP1〜4＋会費（6,000円〜／途中入会1,000円）
9. **写真・会報誌**（旧サイドバー：滝川鯉昇爆笑会の写真、ほうじんナウ91〜105号）
10. **事務局アクセス**（地図）
11. **国税・関連情報**：和風メニューバナー24枚（国税・法人会・保障・地域の4色）＋そのほかのリンク
12. **CTA**：電話・入会案内

スマホでは少しスクロールすると画面下に「電話で相談／入会のご案内」を固定表示（`components/StickyCta.tsx`）。

## 現行サイトからの移植状況

| 現行の掲載内容 | 新サイトでの場所 |
| --- | --- |
| トップ：メイン画像 | 宿場町のイラストに差し替え（※実写写真に差し替え予定） |
| トップ：お知らせ・会員募集中の文・地図・バナー16件 | トップ（お知らせ・法人会とは・事務局・国税関連情報） |
| 全ページ共通：滝川鯉昇爆笑会（美里支部）写真・ほうじんナウ91〜105号 | 各ページ下部の共通ブロック（`components/SideInfo.tsx`） |
| 法人会とは：本文・支部所在地表・会員加入状況（5年分） | `/about` |
| 活動案内：概況・表1・表2・活動報告1〜8・租税教室2表・支部活動表 | `/activity`（原文のまま、明らかな誤字のみ修正） |
| 入会案内：メリット画像（メリットの樹）・年会費・納入方法・中途入会・申込書4種 | `/join`（メリットの樹は画像＋テキストで掲載） |
| 福利厚生制度：全制度・取扱会社・電話番号 | `/welfare` |
| 情報公開：全PDF・貸借対照表9年分 | `/disclosure` |
| お問い合せ：住所・電話・FAX・地図 | `/contact` |
| お知らせ一覧：全51件（コーチング研修会の申込フォーム・画像含む） | `/news` |
| リンク集：8件 | `/links` |
| 個人情報保護方針 | `/privacy`（原文のまま） |

修正した誤字：「制度がが」→「制度が」、「6．域社会貢献運動」→「地域社会貢献運動」、「やさしいい決算書」→「やさしい決算書」、「キャシュフロー」→「キャッシュフロー」。

画像の扱い：メニューバナーは `和風モダンな法人会メニューグリッド.png` から切り出し（520×90、WebP）。爆笑会写真・メリットの樹・コーチング研修会の画像は `public/images/` にコピー済み。**PDFは旧WordPressの `wp-content/uploads` を直接参照**しています。
